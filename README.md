# ITC Git and GitHub Advance Exercises
This repository contains scripts for exercise on git stash, reset/revert, and interactive rebase.


## What to do with this repository?
### 1. Fork it
Fork your own copy of this repository by clicking on the "Fork" button.

### 2. Clone it
Before cloning the repository, make sure you are in your **Desktop** directory/folder. (We are doing this in _desktop_ for simplicity's sake)

#### Windows
Open your preferred terminal and run
``` powershell
cd C:\Users\<username>\Desktop
```

#### macOS
Open **Terminal** and run
``` bash
cd ~/Desktop
```

Once you are on your Desktop, clone the repository:
``` bash
git clone <repository-url>
```

After cloning the repository, a folder with the same name will appear on your Desktop.

Open this folder using **Visual Studio Code** to start the exercises. Happy learning!

## Additional Instructions
The scripts inside this repo will populate your git log. This is to set-up your local repository for the exercises.

Run the scripts in your preferred editor (The commands to run your script will be provided before the exercise).
